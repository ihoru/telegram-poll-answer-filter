# Фильтр участников Telegram-опроса по ответу

Локальная read-only утилита на Python и Telethon. Она получает ссылку на
неанонимный Telegram-опрос и точный текст одного ответа, после чего показывает
людей, которые участвовали в опросе, но не выбрали этот ответ.

Утилита ничего не пишет в Telegram, никого не удаляет и не сохраняет список
людей в файл.

## Требования и ограничения

- Python 3.12.
- Используется пользовательский Telegram-аккаунт; bot token не поддерживается.
- Аккаунт должен иметь доступ к группе и сам проголосовать в опросе. Иначе
  Telegram возвращает `POLL_VOTE_REQUIRED`.
- Поддерживаются группы и супергруппы. Broadcast-каналы не поддерживаются.
- Опрос должен быть неанонимным. Telegram не раскрывает личности участников
  анонимного опроса.
- Можно анализировать открытый опрос, но результат будет только моментальным
  снимком. Если количество голосов меняется во время чтения, команда отменяет
  результат и просит запустить её снова.
- В результат входят все проголосовавшие, которых вернул Telegram, даже если
  они уже вышли из группы. Текущий аккаунт и администраторы не исключаются.
- Голоса от имени каналов отклоняются: их нельзя безопасно связать с человеком.

Для опроса с несколькими вариантами человек не попадёт в результат, если хотя
бы один из выбранных вариантов совпадает с целевым. Человек, оставивший только
свободный ответ, считается участником, не выбравшим целевой готовый вариант.

## Установка

```bash
cd /home/ihoru/tmp/telegram-poll-answer-filter
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Создайте локальные настройки:

```bash
cp .env.example .env
chmod 600 .env
```

```dotenv
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
TELEGRAM_SESSION=telegram_poll_answer_filter
```

`api_id` и `api_hash` создаются в **API development tools** на
[my.telegram.org](https://my.telegram.org). `api_hash`, коды входа, пароль 2FA
и создаваемый `*.session` нельзя публиковать или передавать другим людям.

При первом запуске Telethon запросит номер телефона, код Telegram и пароль 2FA,
если он включён. Затем авторизация сохранится в локальном session-файле.

## Запуск

```bash
python list_without_answer.py \
  --poll-link "https://t.me/c/1234567890/42" \
  --answer "Точный текст ответа"
```

Текст ответа сравнивается полностью и с учётом регистра. Если совпадений нет
или одинаковый текст встретился несколько раз, команда покажет все доступные
варианты и завершится без результата.

Порядок столбцов:

```text
ID  username  first name  last name
```

После таблицы выводятся вопрос, исключаемый ответ, состояние опроса и количества
участников. Отсутствующие `username`, `first name` или `last name` отображаются
как пустые ячейки.

## Проверки для разработки

```bash
python -m pip install -r requirements-dev.txt
ruff check .
python -m unittest discover -s tests -v
python -m compileall -q .
```

## Безопасность данных

`.env` и `*.session*` исключены из Git. Session-файл даёт доступ к Telegram-
аккаунту; храните его только локально. Если он мог попасть к посторонним,
завершите соответствующий сеанс в **Telegram → Настройки → Устройства**.
